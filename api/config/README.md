# config/ — Laravel Configuration

## Configuraciones del negocio

| Archivo | Propósito |
|---|---|
| `sistema.php` | Configuración propia del sistema (pares principales, límites, etc.) |
| `fifo.php` | Configuración del motor FIFO (pool de pagadores, porcentajes) |
| `permission.php` | Configuración de Spatie Permission (roles y permisos) |
| `reportes.php` | Configuración de generación de reportes |
| `horizon.php` | Configuración de Laravel Horizon (queues, workers) |

## Configuraciones estándar Laravel

`app.php`, `auth.php`, `cache.php`, `cors.php`, `database.php`, `dompdf.php`, `excel.php`, `filesystems.php`, `logging.php`, `mail.php`, `queue.php`, `sanctum.php`, `services.php`, `session.php`
