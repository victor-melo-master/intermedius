# Política de Seguridad — Intermedius

## Reporte de Vulnerabilidades

Si descubrís una vulnerabilidad de seguridad, por favor **NO** la reportes públicamente en GitHub Issues.  
En su lugar, envía un email a: **seguridad@intermediusg.com**

Incluí:
- Descripción detallada del problema
- Pasos para reproducirlo
- Impacto potencial
- Sugerencias de mitigación (si tenés)

Responderemos en un plazo máximo de 72 horas.

## Versiones Soportadas

| Versión | Soportada |
|---|---|
| 1.x (actual) | ✅ |
| < 1.0 | ❌ |

## Proceso de Respuesta

1. Recibimos el reporte
2. Confirmamos la vulnerabilidad
3. Desarrollamos un fix
4. Publicamos una nueva versión con el fix
5. Divulgamos la vulnerabilidad (si aplica) 30 días después del fix
