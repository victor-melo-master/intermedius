# Cambios — Sesión 2026-07-20: Solicitud + Calculadora Bidireccional

## Resumen

Flujo multi-paso simplificado: el formulario de operación solo crea solicitudes (sin movimientos).
Calculadora bidireccional para monto/tasa/bolívares. Redirección automática a gestión.
Montos visibles en el listado desde `monto_solicitado`.

---

## API

### Nuevos archivos

| Archivo | Descripción |
|---------|-------------|
| `api/database/migrations/2026_07_20_213739_add_monto_solicitado_to_operaciones_table.php` | Columna `monto_solicitado decimal(20,2) nullable` en `operaciones` |
| `api/app/Http/Requests/Operacion/SolicitudOperacionRequest.php` | Validación dedicada para `POST /operaciones/solicitud` — no pide `movimientos`, pide `monto_solicitado` requerido |
| `api/app/Http/Resources/TransaccionResource.php` | Resource JSON para `Transaccion` (moneda, cuentas, monto, estado, comprobante) |

### Archivos modificados

#### `OperacionController.php`
- **Import nuevo:** `SolicitudOperacionRequest`
- **`solicitud()`**: Cambia de `StoreOperacionRequest` → `SolicitudOperacionRequest`
- **`index()`**: Nuevo filtro `->when($request->filled('estado'), ...)`

#### `OperacionResource.php`
- Agregado `monto_solicitado` (string|null)
- Agregado `estado`
- Agregado `transacciones` via `TransaccionResource::collection`

#### `Operacion.php` (Model)
- `monto_solicitado` agregado a `$fillable`

#### `RegistroOperacionService.php`
- `crearSolicitud()` ahora persiste `'monto_solicitado' => $payload['monto_solicitado'] ?? null`

## Frontend

### Archivos modificados

#### `frontend/src/composables/useOperacionForm.js`
- **Eliminados:** `watchEffect`, `montoCalculado`, flujo selector
- **`submit()`**: Envía `monto_solicitado` en vez de `movimientos[]`
- **`formularioValido()`**: Valida tasa + cliente + monto_usd (sin movimientos)
- Retorna `quoteSimbolo` para `CalculadoraBidireccional`

#### `frontend/src/views/operaciones/OperacionFormView.vue`
- **Reemplazado** sección de tasa+monto inline por `<CalculadoraBidireccional>`
- **Auto-redirect:** `watch(successRef)` → `router.push(/operaciones/:id/gestionar)` después de 800ms
- Imports: `watch` (vue), `useRouter` (vue-router), `CalculadoraBidireccional`

#### `frontend/src/views/operaciones/OperacionesView.vue`
- **`montoUsd()`**: 3 niveles de fallback: movimientos → transacciones → `op.monto_solicitado`
- **`bolivares()`**: 3 niveles: movimientos → transacciones → `montoUsd × tasa_aplicada`
- **Filtro `estado`** nuevo: Solicitud, En Progreso, Cerrada, Cancelada
- **`estatusBadge()`**: Chequea `op.estado` primero, cae a legacy `estatus`
